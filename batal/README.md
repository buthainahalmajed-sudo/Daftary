# بطل — تطبيق متابعة وانضباط

تطبيق ويب (PWA) يفتح على جوالك وجواله، ويتزامن بينهما بنفس طريقة **دفتري**:
GitHub Pages للاستضافة، و**GitHub Gist + توكن** للمزامنة.

---

## ١) ارفعيه على GitHub Pages

```bash
git remote add origin https://github.com/<حسابك>/Batal.git
git push -u origin main
```

ثم في صفحة المستودع: **Settings ← Pages ← Source: Deploy from a branch ← main / (root)**.
بعد دقيقة يصير الرابط:

```
https://<حسابك>.github.io/Batal/
```

## ٢) اربطي الجوالين (نفس خطوات دفتري)

1. **أنشئي Gist خاص**: [gist.github.com](https://gist.github.com) ← اسم الملف `batal-data.json` ← المحتوى `{}` ← **Create secret gist**.
   انسخي معرّف الـ Gist من الرابط (الجزء الطويل بعد اسم المستخدم).
2. **أنشئي توكن**: GitHub ← Settings ← Developer settings ← Personal access tokens ← **Tokens (classic)** ← Generate new token ← صلاحية **gist** فقط.
3. **في جوالك (أول جهاز)**: افتحي الرابط ← اختاري **👩 جوال الأم** ← الإعدادات ← الصقي الـ Gist ID والتوكن ← اضغطي **🔼 هذا أول جهاز — ارفعي بياناته**.
4. **في جواله (الجهاز الثاني)**: نفس الرابط ← اختاري **🧒 جوال الطفل** ← نفس القيمتين ← اضغطي **🔽 هذا جهاز ثانٍ — اسحبي البيانات الموجودة**.

**دور الجهاز يخص كل جوال وحده ولا يتزامن.** على جوالك يفتح التطبيق مباشرة على شاشة ماما، وزر 👩/🧒 في الأعلى يبدّل بين الشاشتين بحرية. وعلى جواله **ما فيه شاشة ماما إطلاقًا** — لا زر ولا خيار في الإعدادات.

**لا يوجد رمز ولا كلمة مرور في التطبيق.** الحماية بالدور نفسه لا بكلمة تُنسى أو تُشاف.
لإرجاع شاشة ماما على جهاز صار «جوال البطل»: **اضغطي مطوّلًا على الكرة ⚽ في أعلى الشاشة ٣ ثوانٍ**، وبيسألك تأكيد.

## حجم الخط

الإعدادات ← **حجم الخط** ← − / + (من ٩٠٪ إلى ١٧٠٪). يخص كل جوال وحده ولا يتزامن، فتكبّرينه عندك وتخلّينه عنده كما يريحه.

بعدها يتزامن لحاله: كل تغيير يُرفع خلال ثوانٍ، وكل جهاز يسحب الجديد كل ٤٥ ثانية وعند فتح التطبيق.

## ٣) ثبّتيه على الجوال

- **آيفون**: سفاري ← مشاركة ← *إضافة إلى الشاشة الرئيسية*.
- **أندرويد**: كروم ← القائمة ← *تثبيت التطبيق*.

## وقت الأجهزة — العدّاد والصافرات

**الحد اليومي:** ساعة في اليوم الدراسي (أحد–خميس)، وثلاث ساعات في الإجازة (جمعة وسبت).
يقدر يجمع أكثر بالنقاط، لكن اليوم الواحد ما يتجاوز حده — والباقي يبقى برصيده لبكرة. الحدّان قابلان للتعديل.

**الجلسة:** يضغط «ابدأ» (أو تشغّلينها أنتِ من جوالك) ← 🔔 **صفّارة بداية** ← عدّاد ← صفّارتان قصيرتان قبل النهاية بـ٥ دقائق ← 🔔 **صفّارة النهاية الثلاثية**. الصافرات تُولَّد داخل التطبيق (WebAudio) بلا ملفات صوت، ومعها اهتزاز.

**التجاوز:** لو ما وقف، العدّاد يستمر بالسالب والوقت الزائد ينخصم من رصيده تلقائيًا، ويظهر لك تنبيه في «بانتظارك». الجلسة المنسيّة تُقفل من نفسها بعد ٦٠ دقيقة تجاوز حتى لا تأكل الرصيد كله.

**قيد تقني صريح:** التطبيق صفحة ويب — ما يعرف أنه فتح لعبة، فالبداية دائمًا بضغطة. والرنّة النهائية **على جواله وهو داخل لعبة غير مضمونة**: النظام يجمّد الصفحات في الخلفية، خصوصًا على الآيفون. التطبيق يرفع الاحتمال (نغمة صامتة تبقي الصفحة حيّة + `wakeLock`) ويرنّ حتمًا لحظة ما يرجع للتطبيق. **الرنّة المضمونة هي على جوالك أنتِ** — لأن التطبيق مفتوح عندك.

> الصوت في المتصفح ما يشتغل إلا بعد أول ضغطة على الصفحة. لو ظهرت بطاقة «🔔 فعّل الصوت» في شاشة الوقت، اضغطي «جرّب صفّارة البداية» مرة واحدة على كل جهاز.

## زيادة الوقت كمكافأة على الاجتهاد

من **شاشة الأم ← ⏱️ الوقت**: أزرار ‎+١٥ / +٣٠ / +ساعة / +ساعتين‎ و‎−١٥ / −٣٠ / −ساعة‎، وخانة رقم حر، مع سبب يظهر له.

وفيها خيار **«ترفع حد اليوم كمان بنفس المقدار»**: أشّريها لما تبين المنحة تتجاوز السقف اليومي (اجتهد في اختبار مثلًا) — بدونها الوقت ينضاف لرصيده لكن يبقى محكومًا بحد اليوم.

## ملاحظات

- **ما فيه رمز ولا كلمة مرور** — الحماية بدور الجهاز، والضغطة المطوّلة على الكرة ⚽ (٣ ثوانٍ) هي باب الرجوع الوحيد على جوال البطل.
- التوكن يُحفظ داخل متصفح كل جهاز — بما فيها جواله. اختاري توكن بصلاحية **gist فقط**، بحيث لو انكشف ما يوصل لشيء ثاني.
- خيار **«المهام تحتاج تأكيدك»** مفعّل افتراضيًا: يعلّم المهمة، وتنحسب النقاط بعد تأكيدك من صندوق «بانتظارك».
- كل حركة نقاط مسجّلة في دفتر داخلي، والرصيد محسوب منه — فسحب التأكيد يرجّع النقاط والمكافآت المرتبطة به تلقائيًا.
